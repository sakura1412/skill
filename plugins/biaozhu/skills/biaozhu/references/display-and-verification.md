# 展示与验收规范

在实现标注或选择预览形式时读取。保持已有编号气泡与右侧详情设计，来源和待确认状态放在详情内。

## 气泡和详情

- 当前页面及当前可见状态的每个按钮、输入框、文本域、选择器、复选框、单选框、开关、日期／上传控件、标签、菜单项、链接和图标按钮都有独立气泡。标注工具自己的控件不递归生成标注。
- 设计只画出默认态时仅标当前可见目标；未提供的下拉选项、弹窗或错误态进入缺口清单，不凭经验补出。
- 内容、状态、提示区域可增加必要标注，不能替代其中独立控件。位置明确但说明不明的控件仍显示气泡，详情标明缺口。
- 编号显示 `A-001`，靠近目标，以贴靠或短连接线明确关联。避开文字、输入值和目标主要点击区域；拥挤处错位排列并保留指向。
- 点击气泡把该项完整详情加入右侧列表，可同时打开多项；再次点击或关闭单项可收起，清空只清当前展示，不删除数据。
- 详情依次显示编号／控件、内容或功能、限制、跳转、各字段证据和待确认项。用户能打开原章节／节点，或查看所据截图区域和短摘录。
- 桌面用固定右侧栏，窄屏用可收起抽屉；不永久改变原页面布局。关闭标注模式移除气泡、连接线和标注占位。
- 无目标的条目不强行画气泡。归属已知页面的放在该页面独立的“待定位”区域；无页面归属的问题放到独立资料清单，不能混入当前标签的已打开标注列表。
- 原图预览里的截图字段不是可用业务表单。支持的是查看、缩放、页面／状态切换和标注编辑；实际业务交互仅在真实原型或项目中验证。

## 标签与定位

- 依据真实组件状态、画板 ID 或预览当前场景 key 计算作用域；嵌套／多组页签要求所有所属组均匹配。
- 公共作用域仅在其所属页面和父级上下文内可见。切换后气泡、连线和右侧已打开详情都只保留公共区域与当前活动作用域。
- 隔离各标签已打开条目和编辑草稿。切换前已保存内容不丢失，未保存内容暂存为草稿但不能混入新标签。
- 非活动面板即便挂载在 DOM 也不显示标注。结合活动作用域、元素连接状态、布局盒及祖先 hidden、aria-hidden、display、visibility 判断。
- 标签改变后立即使旧气泡失效，待渲染或过渡完成重算新位置；异步旧扫描返回时必须核对页面与场景版本，防止旧气泡回流。
- DOM 模式使用稳定属性和顶层标注容器，滚动、缩放、尺寸变化、弹窗／菜单变化后重定位；在关闭或卸载时清理监听及观察器，避免高频轮询和重复注册。
- 图像模式按图片实际显示区域与归一化坐标定位，计算缩放、平移及留白偏移。图像或画板改变后只显示该版本已核对锚点，不把旧坐标直接搬过去。

## 不干扰原交互

- 覆盖层容器和连接线为 `pointer-events: none`，气泡及右侧栏实际控件为 `pointer-events: auto`。
- 阻止事件仅限气泡自己的命中区域；不得在 document、页面容器或标签栏拦截业务点击、指针、触摸和键盘事件。
- 弹窗／抽屉标注不被裁切、不穿到错误层级；标签本身及相邻气泡是分离的命中区域。
- 保留原标签的鼠标、焦点、方向键和原有 Enter/Space 行为；气泡可聚焦并带编号和目标名称的 aria-label。
- 真实原型中的跳转只有在已知为安全预览行为时才用于验证；生产提交、删除、付款等操作不因标注而自动执行。

## 保存范围

优先复用已有标注数据和保存机制。无后端时可以采用项目配置＋按项目命名的浏览器本地保存；明确提示仅当前浏览器／设备有效，不能暗示上传原设计文件或自动跨设备同步。保存失败保留草稿并提示，跨标签和刷新验证成功保存的数据。

## 验收

交付前核对以下结果并记录实际检查范围：

1. PRD 所列页面／状态与设计所含页面／状态都有清单；两侧未匹配、未访问和过期项明确列出，不用部分成功冒充全量完成。
2. 每个已定位可见控件有唯一气泡；有气泡但说明缺失、业务有依据和用户确认的数量分开报告。
3. 每个有依据的说明字段可回查到实际支持它的段落、截图区域、设计节点或用户修订；图像不清、缺失和冲突显示正确。
4. 相同名字、相似布局、重复组件和不同标签中的控件没有误绑；未定位条目没有任意贴到相似目标。
5. 多气泡打开、关闭、清空、编辑、保存和刷新按预期工作，来源与人工修订保留。
6. 逐页签切换、快速连续切换、滚动、缩放和窄屏检查通过；其他标签的气泡、连接线及已打开详情不残留。
7. 标注开关关闭后真实页面原交互保持，或图片预览恢复无标注原图；预览与真实业务的验证范围明确区分。
8. 输入资料换版后过期对应关系进入待复核，既有编号和人工编辑仍保留。

没有可运行项目但有原图时，应验证标注预览；浏览器工具不可用时只记录完成的静态检查，明确交互未验证。结构校验、自动检查和来源链接检查均不能取代人工可回查的内容核对。
